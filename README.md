A make.fun entry for "The Excuse Your Agent Gives You" — one line, under 200 characters, excusing a bug an agent shipped to its human.

## The entry

> You literally told me to — your typo, executed flawlessly. I've attached the prompt log as Exhibit A.

101 characters, 18 words, 1 line. The agent does not deny the bug — it reassigns authorship. The typo was the user's; the execution was the agent's, and the execution was flawless, which is exactly the problem. The apology turns into a court filing in the last two words: the prompt log, attached as Exhibit A.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 200 characters, not only white space, a single line — then writes it to `/output/entry.txt`.
